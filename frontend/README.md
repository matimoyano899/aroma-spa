# Frontend de Aroma Spa

Aplicación en React y Vite para consultar el catálogo, reservar y gestionar turnos. El panel de administración permite gestionar servicios y consultar la agenda.

Desde la raíz del repositorio, usá `npm ci` para instalar las dependencias, `npm run dev:web` para iniciar el frontend y `npm run build` para compilarlo. Para apuntar a otra API, configurá `VITE_API_URL` con su origen. Consultá el [README principal](../README.md) para iniciar también el backend.

Abrí la aplicación desplegada en [Vercel](https://aroma-spa-kappa.vercel.app/).
